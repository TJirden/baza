# Baza

**Baza** — Telegram-бот для каталогизации, интеллектуального поиска и соревновательного сравнения мемов.

### Основной функционал
* **Анализ и OCR**: Автоматическое распознавание текста на изображениях и генерация описания сцен при помощи Vision-модели (moondream) через Ollama.
* **Гибридный поиск**: Комбинация семантического векторного поиска (`pgvector` + `all-minilm`) и текстового поиска (`ILIKE`) с ранжированием результатов через Reciprocal Rank Fusion (RRF) и нормализацией «е/ё».
* **Мем-Баттлы**: Периодические автоматические голосования за лучшие мемы в групповых чатах с расчетом ELO-рейтинга мемов.
* **PvP-Дуэли**: Вызовы между пользователями на очки ставок (`/duel @username <ставка>`) с выбором мема в ЛС и проведением дуэли в общем чате.

## Команды запуска

**1. Поднятие инфраструктуры**
```bash
docker-compose up -d
```

**2. Загрузка модели эмбеддингов**
```bash
docker exec -it ollama ollama pull all-minilm
```

---

## Сборка и запуск через Gradle

Если инфраструктура в Docker уже запущена, используйте следующие команды для сборки и запуска самого приложения:

**1. Сборка JAR-файла**
```bash
./gradlew clean build
```

**2. Запуск приложения**
```bash
./gradlew bootRun
```
