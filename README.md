# Baza

**Baza** — Telegram-бот для каталогизации, интеллектуального поиска и соревновательного сравнения мемов.

### Основной функционал
* **Анализ и OCR**: Автоматическое распознавание текста на изображениях и генерация описания сцен при помощи мультимодальной модели Google Gemini 3.5.
* **Гибридный поиск**: Комбинация семантического векторного поиска (`pgvector` + Google GenAI `gemini-embedding-001`) и текстового поиска (`ILIKE`) с ранжированием результатов через Reciprocal Rank Fusion (RRF) и нормализацией «е/ё».
* **Мем-Баттлы**: Периодические автоматические голосования за лучшие мемы в групповых чатах с расчетом ELO-рейтинга мемов.
* **PvP-Дуэли**: Вызовы между пользователями на очки ставок (`/duel @username <ставка>`) с выбором мема в ЛС и проведением дуэли в общем чате.
* **Интеллектуальные дайджесты**: Автоматическая и ручная генерация дайджестов лучших мемов группы с ИИ-саммаризацией при помощи LLM (`/digest`).

## Команды запуска

**1. Поднятие инфраструктуры**
```bash
docker-compose up -d
```

---

## Сборка и запуск через Gradle

Если инфраструктура в Docker уже запущена, используйте следующие команды для сборки и запуска самого приложения:

**1. Сборка JAR-файла**
```bash
./gradlew clean build
```

**2. Запуск приложения**
```bash
./gradlew bootRun
```

---


## Запуск и переменные окружения (.env)

При компиляции и запуске необходимо также указать `environment variables` любым удобным способом:

* **`TELEGRAM_TOKEN`**: Токен бота
* **`GEMINI_API_KEY`**: API-ключ Google Gemini
* **`GOOGLE_CLOUD_PROJECT`**: Идентификатор проекта Google Cloud (необязательно, по умолчанию используется dummy-project)

---

## Тестирование

**1. Запуск юнит и интеграционных тестов**
```bash
./gradlew test
```

**2. Запуск нагрузочных тестов (k6)**
Для проведения нагрузочного тестирования API поиска выполните команду:
```bash
k6 run load-test.js
```
